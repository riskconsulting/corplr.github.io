## 🚀 How to Run Locally

No build step or complex server installation required. SENTINEL runs directly in any modern browser:

### Option 1: Double-Click
Simply double-click `index.html` to open in Google Chrome, Microsoft Edge, Brave, or Safari.

### Option 2: Local Web Server (Node.js)
```bash
# Clone the repository
git clone https://github.com/<your-username>/sentinel-financial-defense-os.git
cd sentinel-financial-defense-os

# Start a lightweight local server
npm start
# or: npx serve .
```
Visit `http://localhost:3000` in your browser.

## 🌐 Deploy to GitHub Pages (Free Instant Hosting)

Host this entire platform live on the web with zero server costs in **under 2 minutes**:

1. Push this repository to GitHub.
2. Go to repository **Settings** &rarr; **Pages** (left sidebar).
3. Under **Build and deployment** &rarr; **Source**: Select `Deploy from a branch`.
4. Under **Branch**: Select `main` and folder `/(root)`, then click **Save**.
5. Within 60 seconds, your site will be live at:  
   `https://<your-username>.github.io/<repository-name>/`
